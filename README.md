# Basic Router Configuration – Cisco Packet Tracer
## About

This Packet Tracer file is a basic practice setup for learning Cisco router configuration.

## What I Practiced

* Basic router configuration
* Setting router hostname
* Configuring IP addresses
* Enabling router interfaces
* Checking interface status
* Basic connectivity testing using `ping`

## Commands Practiced

enable
configure terminal
hostname R1
interface gigabitEthernet 0/0
ip address <IP> <Subnet Mask>
no shutdown

I used the `ping` command to check connectivity between devices.

## Tool Used

Cisco Packet Tracer

## Purpose

This file is created for learning and practicing basic networking and router configuration.
